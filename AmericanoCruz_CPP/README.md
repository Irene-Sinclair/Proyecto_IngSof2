# Americano Cruz - C++

Implementación orientada a objetos basada en los modelos de análisis y diseño del Grupo #1.

Incluye:
- Usuario
- Producto
- FormaPago
- DetalleVenta
- Venta
- MovimientoInventario
- Repositorios
- Servicios
- Controladores
- Vistas

El portal web funcional usa Supabase/PostgreSQL para facilitar la demostración. Este código C++ documenta e implementa la estructura de clases solicitada en la asignatura.

Compilar:
```
g++ -std=c++17 AmericanoCruz.cpp -o AmericanoCruz
```
